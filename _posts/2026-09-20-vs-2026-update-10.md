Visual Studio 2026 Update 10 is now available. This update includes several improvements and bug fixes for the Visual C++ compiler release including a matching [STL](https://github.com/microsoft/STL/wiki/Changelog#msvc-build-tools-1452) release. For a summary of changes for 18.7 to 18.10, see the [Visual C++ Team Blog](https://devblogs.microsoft.com/cppblog/whats-new-for-c-developers-in-visual-studio-2026-18-7-18-10/).

<!--more-->

<strong>CMake:</strong> VS 2026 ships with [CMake 4.3.1](https://cmake.org/cmake/help/v4.3/release/4.3.html) which was included in Update 7.

<strong>Clang:</strong> VS 2026 ships with clang v22.1.3 which was included in Update 7.

<strong>NuGet:</strong> Update 7 added official native code support for *PackageReference* per [this blog post](https://devblogs.microsoft.com/cppblog/nuget-packagereference-for-c-projects-in-visual-studio/).
